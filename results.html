Student Result Generator

Government Primary School Pethgam Wagoora • Offline-ready single HTML file

1. Class-wise Marks Entry & Student Photographs

Upload the school Excel workbook first. Select a class, assessment and subject, load the class roster, and enter marks against each student. Student photographs are assigned manually to each student in the Photograph Upload section. The school logo is loaded automatically from new-logo.png.

Upload the class-wise student workbook to begin.

2. Student Photograph Upload

Select a class and choose one or more JPG, PNG, or WebP images. Assign every photograph to the correct student manually using the student selector beside each image. Image filenames are not used to identify or auto-select students. The school logo is separate and loads from new-logo.png.

Choose one or more JPG, PNG, or WebP images.
Upload the student workbook first, then select photos for a class.

3. Class-wise Monthly Attendance

Select a class and month, load its students, and enter the number of days present for each student. Attendance is saved in this browser and appears on the student's printed marksheet.

Enter the total working days for the selected class and month.
Supports the “Automatic_FIXED.xlsx” layout (Admission No., Student Name, Class, and monthly columns for Days Attended, B/F Days, Cumulative Days, No. of Working Days).
Upload the workbook and load a class to enter monthly attendance.

4. Co-Scholastic / Life Skills Entry

Enter a grade, level, or short assessment for each skill. These values will appear in the student's printed progress report.

4. Marks Entry & Grade-Point Settings

Enter marks in the FA, T(30), CC(20), or Sum(50) columns. The app calculates totals, percentages, grades, grade points, proficiency and overall result automatically. The sample data below is editable.
